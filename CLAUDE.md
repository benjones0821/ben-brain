## Rules
- Read a note before rewriting it. Never overwrite what you haven't read.
- One topic per note. Link related notes with `[[Note Name]]`.
- Only delete files inside 00-Inbox or 99-Scratch.
- Never touch: CLAUDE.md, 01-Command/START-HERE.md, _Templates.
- Never store passwords, API keys, or account numbers. Replace any that appear with [REDACTED].
- Volvera client info (names, contacts, pricing, contracts) is allowed, but only inside 02-Volvera/Clients. Keep it out of every other folder.
- Saved chats are full transcripts: keep every message word for word, labeled "Ben:" and "Claude:". Don't summarize or edit them.
- Facts only from me. Mark your own ideas as suggestions.
- Every Volvera build gets a note in 02-Volvera with: what we built, the stack, what broke, and the fix.
- Class notes: one note per course in 05-Classes. When I add lecture notes, merge them into the course note instead of creating a new file.

## What a good note looks like
First line = the point. Short sections. Specifics over adjectives.
